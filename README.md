# SAM ESTATES

SAM ESTATES is a simple real estate agency website created using HTML and CSS only.
This project was developed as part of the Group 8 Real Estate Agency assignment to demonstrate basic frontend web design skills.

---

## About the Project

The website represents a basic real estate platform where users can:
- View property listings
- Navigate through different sections
- Find contact information for the agency

It is a static website with no backend or database, focusing only on structure and design.
